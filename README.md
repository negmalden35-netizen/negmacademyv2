6 — حماية الترخيص

لا تعتمد على وجود ملف أو كود داخل المتصفح فقط.

يجب أن تكون حالة الترخيص في Supabase.

الكود مجرد وسيلة تفعيل.

لا يجوز لمعلم استخدام ترخيص معلم آخر.

ولا يجوز للمعلم تغيير البريد المرتبط بالترخيص من نفسه.

31 — Multi-Tenant Security

هذا شرط أساسي.

كل سجل متعلق بمعلم يجب أن يحتوي على:

teacher_id

أو:

tenant_id

استخدم:

Supabase Row Level Security — RLS

بحيث:

المعلم A لا يستطيع قراءة أو تعديل بيانات المعلم B.

والطالب لا يستطيع الوصول إلى بيانات طالب آخر.

والطالب لا يستطيع الوصول إلى لوحة المعلم.

والمعلم لا يستطيع الوصول إلى Super Admin.

لا تعتمد على إخفاء البيانات في الواجهة فقط.

يجب تطبيق الحماية في قاعدة البيانات نفسها.
